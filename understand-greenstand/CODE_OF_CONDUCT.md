# Code of Conduct

This repo follows
[Greenstand's Code of Conduct](https://github.com/Greenstand/Greenstand-Overview/blob/master/License%2C%20Code%20of%20Conduct%20etc/CODE_OF_CONDUCT.md),
version 1.4 of the Contributor Covenant. It applies to everyone who takes part here: in issues,
in pull requests, and in comments.

To report unacceptable behavior, follow the
[Enforcement](https://github.com/Greenstand/Greenstand-Overview/blob/master/License%2C%20Code%20of%20Conduct%20etc/CODE_OF_CONDUCT.md#enforcement)
section of that Code of Conduct.
