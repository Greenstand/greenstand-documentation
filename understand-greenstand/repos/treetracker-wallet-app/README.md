# treetracker-wallet-app

Machine-generated documentation for [`Greenstand/treetracker-wallet-app`](https://github.com/Greenstand/treetracker-wallet-app),
the Greenstand Treetracker Wallet App: a Yarn v4 monorepo containing a Next.js web
wallet, an Expo React Native mobile wallet, a NestJS backend service, a Cucumber/
WebdriverIO BDD test suite, and shared TypeScript packages (Keycloak auth, wallet API
client, Jotai state, PostgreSQL pub/sub queue) for secure digital token transfers tied to
tree-planting and forest-management activity. Today the web wallet is the live client. The
mobile wallet uses mock data on most screens.

## Business domains

- **Authentication and Identity**: sign-in and registration through the Keycloak hosted pages, the session, and the account profile. The NestJS user API sends password login, user creation, and the profile to Keycloak.
- **Wallet Management**: the dashboard of token and wallet totals, wallet creation, the wallet profile, the tokens of a wallet, and the history of each token.
- **Token Transfer**: send a bundle of tokens to a wallet. The receiver accepts or declines it, and the sender can cancel it while it waits. Both sides see the history.
- **Share Links and Claims**: send tokens to a person without a known wallet, as a signed `/claim` link with a QR code. The public `/claim` page puts the tokens into the wallet of the receiver.
- **Search and Discovery**: find a wallet to send tokens to, or to ask for tokens. The native app and the web `/search` page use hard-coded mock data today.
