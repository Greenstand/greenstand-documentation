## Domains

### Tree Capture

Core grower-facing flow to capture a tree as a geotagged photo. Manages camera, GPS convergence, image review with an optional note, and persistence of the tree record for later sync.

**Terms:** Tree, TreeCapture, Session, Location, TreeAttribute

**Rules:**

- GPS accuracy must converge below a configured threshold before capture
- Every tree binds to an active capture session, user and wallet
- A captured image needs review and approval before the tree persists

**Flows:**

- **Capture a Tree** (`TreeCaptureScreen (camera capture)`): Guides the grower through capturing a geotagged tree photo, reviewing it with a note, and saving the tree record.
- **Record Session Note** (`SessionNoteScreen`): Captures an optional session-level note applied across trees captured in the current session.

### Grower Onboarding & Identity

Handles grower (planter) sign-up, selection of the active grower, and profile management. Collects name and email/phone credentials and registers the grower with the backend.

**Terms:** User, PlanterInfo, PlanterCheckIn, Wallet

**Rules:**

- A grower needs a first and last name plus a valid email or phone credential
- Credentials pass validation before registration
- A user record tracks upload state for backend registration

**Flows:**

- **Sign Up a Grower** (`SignUpScreen`): Multi-step signup that collects a grower name and email/phone credential, validates them, and registers the grower.
- **Select Active Grower** (`UserSelectScreen`): Lists existing growers and selects the active one, with edit and delete support, before proceeding to capture.
- **Manage Grower Profile** (`ProfileScreen`): Displays and edits grower profile fields with validation and supports profile deletion.

### Organization & Wallet Selection

Manages the organization a grower belongs to and the destination wallet that receives captured trees. Supports adding new organizations and wallets during onboarding and capture setup.

**Terms:** Organization, Wallet, User, CaptureSetup

**Rules:**

- Captured trees route to a chosen destination wallet
- An organization identifier configures the capture flow
- A new wallet or org can be added on demand

**Flows:**

- **Select Organization** (`OrgPickerScreen`): Selects the organization a grower belongs to during onboarding, or adds a new one by identifier.
- **Select Destination Wallet** (`WalletSelectScreen`): Chooses the destination wallet that receives captured trees, or adds a new wallet, then persists the capture setup.

### Data Sync & Upload

Background orchestration that uploads growers, sessions, trees, location tracks, device config, and messages to the Treetracker API and image/data bundles to object storage. Runs as a WorkManager worker with progress notifications.

**Terms:** UploadBundle, NewTreeRequest, SessionRequest, TracksRequest, DeviceConfigRequest, RegistrationRequest

**Rules:**

- Sync runs only when internet is available
- Sync steps run in a fixed order and propagate failures
- Uploaded records are marked to avoid re-upload
- Images upload to object storage and are referenced by URL

**Flows:**

- **Background Data Sync** (`TreeSyncWorker (WorkManager)`): WorkManager worker that orchestrates uploading growers, sessions, trees, device config, and messages with a foreground progress notification.
- **Build Tree Upload Request** (`CreateTreeRequestUseCase`): Builds a NewTreeRequest payload from a stored tree capture plus device metadata for upload.
- **Upload Location Tracks** (`UploadLocationDataUseCase`): Groups pending GPS location data by session into TracksRequests and uploads them, then marks records as uploaded.
- **Upload Images to Object Storage** (`UploadImageUseCase`): Uploads a single image file to DigitalOcean Spaces via the AWS S3 SDK and returns its public URL.

### Grower Messaging

Two-way messaging between growers and the platform: direct chat, announcements, and surveys. Syncs paginated messages from the API, persists them locally, and uploads unsent messages and survey responses.

**Terms:** Message, Survey, Question, MessageEntity, Wallet

**Rules:**

- Messages sync per wallet with API pagination
- A survey collects answers before submitting a response
- Unsent messages upload in windowed bundles

**Flows:**

- **Sync Messages** (`MessagesApiService (GET messages)`): Fetches paginated messages from the API, persists them locally, uploads unsent messages, and exposes the message list.
- **Send Chat Message** (`ChatScreen`): Composes a direct message, tracks the draft, and persists it for upload in the conversation thread.
- **Complete Survey** (`SurveyScreen`): Presents survey questions, navigates between them, collects answers, and submits the survey response.

### Dashboard, Map & App Settings

Grower-facing overview surfaces: a dashboard of sync stats and pending uploads, a map of captured trees, plus app settings and language selection. Provides navigation entry points into the main flows.

**Terms:** TreeMapMarker, SyncProgress, Settings, Language

**Rules:**

- The dashboard shows the count of trees still pending upload
- The map renders only captured tree markers with detail cards
- Settings expose feature toggles and logout

**Flows:**

- **View Dashboard** (`DashboardScreen`): Shows sync stats, pending upload counts, and sync progress, with navigation entry points to main flows.
- **View Tree Map** (`MapScreen`): Renders captured tree markers on a MapLibre map with a carousel of tree detail cards.
- **Manage Settings** (`SettingsScreen`): Lists app options, toggles feature flags and power-user mode, and handles logout.
- **Pick App Language** (`LanguageSelectScreen`): Lets the grower pick and apply the app language from a selectable list.
