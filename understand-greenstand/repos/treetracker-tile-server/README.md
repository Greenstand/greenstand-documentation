## Business domains

- **Map Tile Serving**: the Express service answers tile requests. It renders a 256x256 PNG tile or a UTF grid tile for each request.
- **Tile Stylesheet Composition**: `greenstand/config.js` builds the Mapnik XML style of each tile. Low zoom levels get tree clusters as GeoJSON, and high zoom levels get a PostGIS layer.
- **Tree Query Selection**: `greenstand/Map.js` picks one SQL builder from `greenstand/sqls/` for each tile, by map mode and zoom level.
- **Release and Deployment**: GitHub Actions, the `Dockerfile`, and the Kustomize manifests in `deployment/` release the service and deploy it to development, test, and production.
